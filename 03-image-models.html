03 Ask for a reference, not a miracle

Image models: reference beats prompt

The gap between image models is smaller than the gap between a vague prompt and a reference image. Pick the model by the job, then always give it something to look at.

Most people lose here because they write longer prompts. The people who win upload a picture and say “like this, but mine”. A reference does more work than a paragraph.

03.2The golden rule: always use a reference image

  1. Find a winner on Pinterest or any image post.

  2. Reverse engineer it: upload it to an AI and ask for the layout, colours, text style and mood.

  3. Use it as the reference to make your own version.

Prompt Reverse engineer an image 
Analyze this image. Describe: layout, text hierarchy, color palette, fonts style,
lighting, camera angle, and mood. Then write one prompt I can use in an image model
to recreate this style with my own topic: [YOUR TOPIC]. Do not copy any logos or text.

03.3Three ways to use it

1. Reverse engineer, then regenerate. You get the prompt, change the content, and rebuild the image from scratch. It may not look identical — that is the trade for a clean, original file.

Prompt Consistent infographic series 
give me the infographic/image prompts for the image in 4:5 ratio and add @sifuyik as watermark, so i can generate the same style as the original image with your updated version.
>> Remember that i wont be adding any reference image in each infographic prompt, so each should be individual infographic prompt, so you have to prompt it so their design stay consistent, give me the full prompts of each
>> you need to include the text in the prompt as well so that the ai image generator know what text to include

2. Use the image as a reference and ask the model to edit it directly. This is the closest to the original and the fastest route to a series that matches.

3. Remove the text or the main character and add your own. Keep the layout, swap the content — this is how you reuse a layout you already know works without rebuilding it.

03.4Live demos

  • Sites for image prompts: show your list, save one idea.
  • Reuse a winning template: take one of your best posts, keep the layout, change only the topic text. Do not rebuild from zero.
  • Face comparison: the same photo of you in Nano Banana Pro and ChatGPT. Compare likeness and consistency — Nano Banana Pro looks more natural.
  • Pose website (omilic.com): pick a pose, then use it as a reference.

03.5Make it look real

A reminder from the AI Avatar training. The tells are not in the face — they are in the perfection.

  • Add flaws on purpose: visible pores, uneven light, off-centre framing, a caught-mid-sentence expression.
  • Put “professional photography” in the ban list, not the wish list.
  • Keep the face description identical in every prompt, and change only the light and the background.
