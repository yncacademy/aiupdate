02 One tool per platform

Find niche pages and viral posts

People keep asking me how to find niche pages and viral posts. The answer is boring: use the AI that lives where the content lives. One tool per platform, no third-party spy tool required.

6 platformsCopy-the-pattern rule

Every platform has a model that can already see its content. You do not need a paid spy tool to find out what is working this month.

02.2Live demo

  1. Pick one niche. Use the same one for the rest of the session.

  2. Run it through three platforms from the table — one post-feed platform, one short video, one search platform.

  3. Compare the hooks: what is the first line or first frame doing?

  4. Turn one idea found on X into a Facebook text post, an image, and a short video.

The rule

Copy the pattern, not the post. Change the hook, the points, the examples, the layout and the format. If someone can see the original side by side with yours, you have not done enough.

02.3What “pattern” means

  • The hook shape: a number, a warning, a before/after, a “nobody tells you this”.
  • The structure: how many points, in what order, how long each one runs.
  • The visual system: one image or many, text on image, face on frame, colour.
  • The ask: what the post wants you to do at the end.

Then rebuild all four with your own subject. That is a new post, not a copy.
