# AI Magic Mastery — 2026 Update Training

Student hub for the 2026 update training: latest models, live demos, and the Black Friday / Q4 plan.

Thirteen static pages, no build step, no dependencies. Open `index.html` or visit the published site.

## Structure

- `index.html` — contents / start here
- `00-opening.html` … `09-coach-agent.html` — the ten sections
- `cheatsheet.html` — one-page model cheat sheet (printable)
- `prompts.html` — all 12 prompts, filterable, with copy buttons
- `assets/` — stylesheet, script, section posters, screenshots, demo video

## Publishing

GitHub Pages, branch `main`, folder `/ (root)`. For a custom subdomain, add a `CNAME` record in Cloudflare pointing at `yncacademy.github.io`, then set the custom domain in Settings → Pages.
